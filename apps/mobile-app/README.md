# Openclub Mobile App

This is the Flutter mobile application for Openclub.

## Stack
- Flutter 3.x
- Riverpod (State Management)
- Hive (Local Storage)
- Dio (HTTP Client)
- Socket.IO Client
- Firebase Cloud Messaging (FCM)

## Initialization
To initialize the Flutter app, run:
```bash
flutter create .
```
(Note: Requires Flutter SDK installed)
